REIX Foreclosure API

Live mortgage & tax foreclosure notices for Bexar County, TX — sourced from the County Clerk's public feed, cleaned up, and served as simple JSON. Free to use. Get a key in one request.

1. Get an API key

API keys are issued to signed-in accounts. Accounts are created by REIX. Sign in, then create a key:

# 1) sign in (keep the cookie; the response contains a csrf token)
curl -c jar.txt -X POST https://YOUR-DOMAIN/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "you@company.com", "password": "YOUR-PASSWORD"}'

# 2) create a key, sending that csrf token
curl -b jar.txt -X POST https://YOUR-DOMAIN/api/v1/keys \
  -H "Content-Type: application/json" -H "X-CSRF-Token: THE-CSRF-FROM-STEP-1" \
  -d '{"name": "Acme Real Estate App"}'

Response:

{
  "api_key": "reix_AbCdEf123...",
  "usage": "Send this as the 'X-API-Key' header on requests to /api/v1/*",
  "docs": "/docs"
}
Keep your key private. Access to scanned court documents (PDFs) is not included in an ordinary key; REIX grants it per key to approved partners.

2. Authenticate requests

curl https://YOUR-DOMAIN/api/v1/properties \
  -H "X-API-Key: reix_AbCdEf123..."

3. Endpoints

Method & PathDescription
GET/api/v1/propertiesSearch & list foreclosure notices
GET/api/v1/properties/:idSingle property record
GET/api/v1/stats/summaryCounts by type, city, month
GET/api/v1/metaValid filter values (cities, types)
GET/api/v1/properties?property_key=bexar-mortgage-20261000380One property by its stable key
GET/api/v1/changes?after=<cursor>What changed since your last check (new notices, new or removed documents). Every property has a stable property_key; documents may arrive days after the property.
GET/api/v1/listsThe monthly lists: every sale month with its counts (total, confirmed, provisional, documents complete)
GET/api/v1/lists/<YYYY-MM>One monthly list: all notices for that sale month, paged. Add ?format=csv for the whole month as a CSV file. A notice has a sale_date once it is confirmed from the notice document; until then it is placed by the county filing cycle (list_basis: county_cycle) and may move to another month.
GET/api/v1/properties/<property_key>/documentsEvery document on file for a property (notice, deed of trust, additional and tax documents) with what was read from each. Needs the documents permission on your key.
GET/api/v1/files/<file_id>The PDF of one document. Needs the documents permission.
POST/api/v1/keysCreate an API key (signed-in account required)

4. Query parameters (GET /api/v1/properties)

ParamTypeNotes
countystringBexar (more counties may be added over time; see /api/v1/meta)
qstringMatches against address, doc number, or ZIP
typestringmortgage or tax
citystringExact city name, see /api/v1/meta
zipstringExact ZIP code
yearintFiling year
monthintFiling month (1-12): the county's filing cycle, not necessarily the sale month. Use list_month for the sale month.
list_monthstringA monthly list, YYYY-MM (the sale month when confirmed, otherwise the county's filing cycle)
basisstringconfirmed (real sale date known) or provisional (filing cycle only)
doc_numberstringExact county document number
pageintDefault 1
per_pageintDefault 25, max 100
full_address is a computed field — the county only gives us separate address, city, and zip values (no state field, since this feed is Bexar County, TX only). We concatenate them for you so you don't have to.

6. What is added to a property after the notice

A property is announced first, with its address. Documents and tax figures are gathered afterwards, so these fields fill in over time. The property record always shows the latest.

FieldMeaning
property_keyStable id for the notice, e.g. bexar-mortgage-20261000380. Never changes.
details_hashA short code that changes whenever anything about the property changes (address, sale date, lien position, back taxes, tax figures, any document or what was read from it). Store it; if it differs next time, read the property again.
docs_statusnotice and deed_of_trust, each missing, done or none_found
docs_completetrue when the notice and the deed of trust are both on file
lien_positionfirst or subordinate, from the deed of trust
docs_extraNumber of additional documents on file (modifications, liens, judgments, affidavits...)
docs_taxNumber of tax documents on file (back tax report, tax lien, IRS or federal tax lien)
additional_document_namesNames of the additional and tax documents, in the order added, e.g. ["Lis Pendens", "Back Tax Report"]
back_tax_amount_owedAmount owed from the back tax report, if there is one
taxes_annual, taxes_back_owed, taxes_current_due, taxes_total_due, taxes_yearProperty taxes read from the Bexar County Tax Office (annual tax, back taxes, total due). Empty until checked.
taxes_delinquent_after, taxes_as_of, tax_status, tax_account, tax_linkWhen the taxes become delinquent, the date the figures were read, the lookup status, and a link to the Tax Office record
sale_dateThe confirmed sale date, once read from the notice. Until then the notice sits in the list for its county filing cycle.

7. Documents, in detail

GET /api/v1/properties/<property_key>/documents returns details_hash, docs_status, every file, and a separate additional_documents list:

{
  "property_key": "bexar-mortgage-20261000380",
  "details_hash": "4a7db3e4d61adb77",
  "docs_status": {"notice": "done", "deed_of_trust": "done"},
  "additional_documents": [
    {"file_id": 14, "category": "additional", "document_name": "Lis Pendens", "doc_number": "20260000099",
     "courthouse_url": "https://bexar.tx.publicsearch.us/doc/123", "amount_owed": null,
     "uploaded_at": "2026-11-12T15:02:11", "download_url": "/api/v1/files/14"},
    {"file_id": 15, "category": "tax", "document_name": "Back Tax Report", "doc_number": null,
     "courthouse_url": null, "amount_owed": "5000.00", "uploaded_at": "2026-11-12T15:20:40",
     "download_url": "/api/v1/files/15"}
  ],
  "files": [ ... every document, with role, subtype, facts, sha256 ... ]
}
  • Additional document names: Additional Deed of Trust, Modification (most recent), Lis Pendens, Judgment, Other Lien, Affidavit, Notice, City Lien.
  • Tax document names: Back Tax Report, Tax Lien, IRS Lien, Federal Tax Lien. A back tax report carries amount_owed instead of a document number.
  • courthouse_url links back to the document on the County Clerk's site so anyone can review it.
  • Additional and tax documents never change docs_status or docs_complete.
  • A file is identified by file_id and sha256. A replaced document appears as a removal of the old file and an addition of the new one, so make your import repeatable.
  • What was read from a document (facts) is confirmed by a person and may include names and loan amounts. Treat it as sensitive.

8. Keeping up with changes

Call GET /api/v1/changes?after=<cursor>, save the next_after it returns, and call again later. Each event has an id, a type, the property_key and, for documents, a file_id.

Event typeWhat to do
property_addedA new notice. Read it with /api/v1/properties?property_key=.
property_updatedThe county corrected the property's details. detail.fields says which (e.g. address). Read the property again.
document_addedA document arrived (may be days after the property). Read the documents endpoint.
document_updatedStaff corrected what was read from a document. Read the documents endpoint.
document_removedA document was removed or replaced. Stop using that file_id.
document_none_foundSomeone searched and could not find the deed of trust.
taxes_updatedTax figures were read or changed. detail has taxes_annual, taxes_back_owed, taxes_total_due. Tax figures are refreshed on a rolling basis, and an event is sent only when they change.
sale_date_setThe real sale date was confirmed, which may move the notice to another monthly list.
deeds_updatedOwnership-transfer history was added or changed.
Double-check: once a day, page through /api/v1/properties and compare each details_hash with the one you stored. A different value means something changed: read that property again. This catches anything missed, even if you lost your place in the change feed. We also run our own check every few hours and announce anything on file that was never announced.
