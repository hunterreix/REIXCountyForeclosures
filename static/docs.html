REIX Foreclosure API

Live mortgage & tax foreclosure notices for Bexar County, TX — sourced from the County Clerk's public feed, cleaned up, and served as simple JSON. Free to use. Get a key in one request.

1. Get an API key

No sign-up form, no waiting — post your name/email (optional) and get a key back instantly:

curl -X POST https://YOUR-DOMAIN/api/v1/keys \
  -H "Content-Type: application/json" \
  -d '{"name": "Acme Real Estate App", "email": "dev@acme.com"}'

Response:

{
  "api_key": "reix_AbCdEf123...",
  "usage": "Send this as the 'X-API-Key' header on requests to /api/v1/*",
  "docs": "/docs"
}
Keep your key private. It's tied to a usage counter, not a hard rate limit today — but please be reasonable (poll hourly at most; the underlying county data refreshes on that cadence anyway).

2. Authenticate requests

curl https://YOUR-DOMAIN/api/v1/properties \
  -H "X-API-Key: reix_AbCdEf123..."

3. Endpoints

Method & PathDescription
GET/api/v1/propertiesSearch & list foreclosure notices
GET/api/v1/properties/:idSingle property record
GET/api/v1/stats/summaryCounts by type, city, month
GET/api/v1/metaValid filter values (cities, types)
POST/api/v1/keysCreate a new API key

4. Query parameters (GET /api/v1/properties)

ParamTypeNotes
countystringBexar or Collin (more counties added over time; see /api/v1/meta)
qstringMatches against address, doc number, or ZIP
typestringmortgage or tax
citystringExact city name, see /api/v1/meta
zipstringExact ZIP code
yearintFiling year
monthintFiling month (1-12)
doc_numberstringExact county document number
pageintDefault 1
per_pageintDefault 25, max 100
full_address is a computed field — the county only gives us separate address, city, and zip values (no state field, since this feed is Bexar County, TX only). We concatenate them for you so you don't have to.
